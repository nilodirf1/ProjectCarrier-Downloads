# Project Carrier

A co-op zombie shooter for 1 to 4 players. Fight your way along a subway line, through the city above it and beyond.

One player hosts the game from the app and sends the others a link. Friends can join in their browser or with the app. This works over the internet, so nobody needs to be on the same network. Everyone who joins with the app needs the same version as the host; browser players have nothing to install.

## Download

Get the newest version here: **[Latest release](https://github.com/nilodirf1/ProjectCarrier-Downloads/releases/latest)**

- **Windows:** `ProjectCarrier-Setup-<version>.exe`
- **Mac** (Apple Silicon and Intel): `ProjectCarrier-<version>-mac.dmg`

You only need one of these two files. Ignore the others on the release page.

## Install

Project Carrier isn't signed yet, so Windows and Mac show a warning the first time you open it.

**Windows:** Run the .exe file. If Windows says "Windows protected your PC": click **More info**, then **Run anyway**. If the firewall asks the first time you host: tick **Private networks** and click **Allow access**.

**Mac:** Open the .dmg and drag Project Carrier into **Applications**. If the Mac blocks it the first time you open it: click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**. If the Mac asks about network connections the first time you host: click **Allow**.

## Update

The app checks for new versions automatically. When one is available, a notice shows up in the main menu.

**Windows:** Click **Download**, then **Restart to update**.

**Mac:** Click **Download** to open the download page, then install the new .dmg like the first time.

## VR

VR and non-VR players can play together.

**PC headset** (e.g. Rift S, or a Quest through Link): On Windows, switch **VR: On** in the main menu.

**Quest 3 on its own:** No PC or install needed. The host ticks **Link for a VR headset** in the Host panel and sends that link; open it in the headset's browser.

## Two players on one PC

Two people can share one PC with two screens: one plays with keyboard and mouse, the other with a controller. Each needs their own browser window (a window, not a tab) on their own screen. With the app, the app is one of the two windows.

In each window, open **Two players on one PC?** before you join and set **This window plays with** to **Keyboard & mouse only** or **Controller only**. Use a different name in each, and keep both windows visible, or the controller stops working.

Adding a VR player on the same PC should also work, but is untested.
